# 🛒 E-commerce System (Technical Test)

Sistema de gerenciamento de produtos e pedidos para um e-commerce.

## 🚀 Tecnologias

- Java 21
- Spring Boot 3.3.3
- MySQL
- Spring Security + JWT
- Docker e Docker Compose
- Swagger OpenAPI
- Clean Architecture

## 🧪 Como rodar localmente

```bash
# Compile
mvn clean package

# Suba o ambiente
docker-compose up --build
